# 🧠 Quiz Website

A simple interactive **Quiz Website** built with **HTML, CSS, and JavaScript**.  
Users can answer questions and get their score at the end.

---

## ✨ Features
✅ Multiple-choice quiz  
✅ Score tracking  
✅ Responsive layout for Android & desktop  
✅ Restart button  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)
